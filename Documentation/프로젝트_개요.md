# ZZZ Unity Project — 프로젝트 개요

## 프로젝트 개요
URP 기반 전투 연출 데모. 플레이어(Burnice)가 허수아비를 공격하는 레벨 위에
애니메이션 툴, 이펙트 툴, 렌더 타겟 툴을 에디터 확장으로 제작.

## 폴더 구조
```
Assets/
├── 00.Model/               FBX, 텍스처 원본
├── 01.Characters/          캐릭터 Prefab, Animation, Material
├── 02.Effects/             VFX Graph / Particle System
├── 03.Shaders/             HLSL, ShaderLab, RenderFeature 셰이더
├── 04.Scripts/             런타임 C# (Player, Combat, UI, Utilities)
├── 05.Editor/              에디터 전용 C# (AnimationTool, EffectTool, RenderTargetTool)
├── 06.RenderPipeline/      URP RenderFeature, RendererData, Profiles
├── 07.Scenes/              게임 씬
└── 99.Settings/            URP 세팅 (변경 금지)
```

## 렌더 파이프라인
- **URP** 사용
- RenderFeature는 `06.RenderPipeline/RenderFeatures/` 에 위치
- 셰이더는 `03.Shaders/` 하위 목적별 폴더로 분리

## 코드 작성 규칙
네이밍·파일 템플릿·Animator 해시·null 체크 등 코드 스타일 전반은
[CodingConventions.md](CodingConventions.md) 참고.

## 툴 제작 계획 (로드맵)

### 방향 결정 사항
- **이펙트 툴은 별도로 만들지 않는다** — 이펙트를 전투 타이밍에 묶는 일은
  AnimationConfig의 노티파이 시스템을 확장해서 처리 (타임라인 위 트랙 개념).
  별도 EffectTool은 이펙트 프리팹 브라우저/프리뷰어 수준의 보조 역할만.
- **셰이더 파라미터 편집은 별도 EditorWindow가 아니라 `ShaderGUI` 상속**으로 제작
  (`.shader`에 `CustomEditor` 지정). 키워드 자동 관리가 핵심 가치.
- **전투 중 셰이더 파라미터 연출**(히트 플래시, 디졸브)도 노티파이 트랙으로 처리,
  적용은 `MaterialPropertyBlock` 사용 (머티리얼 에셋 오염 금지).

### 1. 노티파이 시스템 확장 (이펙트)
- [ ] 소켓(본) 바인딩 + 위치/회전 오프셋 — `HumanBodyBones` 또는 본 이름 지정
- [ ] `AttachToBone` 옵션 — 생성 후 본을 따라다닐지 여부
- [ ] 구간형(duration) 노티파이 — 시작~끝 구간 유지형 (오라, 카메라 연출용)
- [ ] 이펙트 풀링 + 섹션 이탈 시 attach된 이펙트 정리 (콤보 캔슬 대응)
- [ ] 루프 클립 노티파이 매 루프 재발동 (`_notifyFired` 루프 단위 리셋)
- [ ] `SendMessage` → 인터페이스/직접 호출로 교체
- [ ] ConfigTool에 노티파이 마커 표시 + 스크럽 시 스폰 위치 기즈모 프리뷰

### 2. 셰이더 & 렌더 (순서대로 진행)
1. [ ] 툰 셰이더 1개 제작 (셀 셰이딩 + 림라이트) → `03.Shaders/`
2. [ ] `ShaderGUI` 작성 — 폴드아웃 그룹핑, 토글 연동 키워드 자동 관리
3. [ ] 아웃라인/포스트 RenderFeature → **렌더 타겟 디버거** (중간 RT 시각화 EditorWindow)
4. [ ] 노티파이 `NotifyType.Material` 트랙 — 파라미터 이름 + 커브 + 지속시간 (히트 플래시 등)

## 작업 시 주의사항
- `99.Settings/` 내 URP 에셋은 직접 수정하지 않음 — 새 Profile/RendererData 생성해서 사용
- Editor 전용 코드에 런타임 의존성 추가 금지
- VFX / Particle은 Prefab으로 만들어 `02.Effects/` 에 저장
