# ZZZ Unity Project — 프로젝트 개요

## 프로젝트 개요
URP 기반 **전투 연출 데모**. 플레이어(Burnice)가 허수아비를 공격하는 레벨 위에서,
콤보·강화공격·피격·회피·패링·루트모션 이동을 **데이터(ScriptableObject) + C# 러너 + 커스텀 에디터 툴**
3층 구조로 구현했다.

> 시스템 내부 동작/문제해결은 [AnimationArchitecture.md](AnimationArchitecture.md),
> 한눈 요약은 [README](../README.md), 코딩 규칙은 [CodingConventions.md](CodingConventions.md),
> 자료구조 선택 철학(면접 대비)은 [면접_자료구조_선택.md](면접_자료구조_선택.md) 참고.

## 무엇을 만들었나 (현재 구현된 것)

| 영역 | 구현물 | 위치 |
|------|--------|------|
| 데이터 전투 시스템 | `AnimationConfig`(섹션·Link·Notify·Module 트랙) | `04.Scripts/AnimationConfig.cs` |
| 단일 러너 | `ConfigState` — config를 파싱해 모든 흐름 구동 | `04.Scripts/Player/StateMachine/States/` |
| 상태 코디네이터 | `PlayerStateMachine` + 입력버퍼/피격/회피/패링/강화공격 트리거 | `04.Scripts/Player/StateMachine/` |
| 이동/루트모션 | `PlayerController` — 본에서 직접 추출, 타겟 워프, 섹션 턴 | `04.Scripts/Player/PlayerController.cs` |
| 섹션 모듈(플러그인) | `WindowModule` 베이스 → `IFrameModule`(무적) / `ParryModule`(패링) | `04.Scripts/Player/StateMachine/Modules/` |
| 전투 판정 | `EnemySensor`(전방 부채꼴 탐지) / `HitTarget` / `IHittable` | `04.Scripts/Combat/` |
| 카메라 | 커스텀 TPS 카메라 (Cinemachine 미사용) | `04.Scripts/Player/TPSCameraController.cs` |
| **에디터 툴** | `AnimationConfigTool` — 타임라인 편집·Combo 프리뷰·라이브 모니터 + FBX 클립 추출 | `05.Editor/AnimationTool/` |

## 폴더 구조
```
Assets/
├── 00.Model/               FBX, 텍스처 원본
├── 01.Characters/          캐릭터 Prefab, Animation, Material, Config 에셋
├── 02.Effects/             VFX/Particle (현재 테스트 머티리얼만 — placeholder)
├── 03.Shaders/             셰이더 (현재 비어 있음 — 로드맵)
├── 04.Scripts/             런타임 C# (Player, Combat, Movement)
├── 05.Editor/              에디터 전용 C# (AnimationTool)
├── 06.RenderPipeline/      RenderFeature (현재 비어 있음 — 로드맵)
├── 99.Scenes/              데모 씬 (SampleScene)
└── 99.Settings/            URP 세팅 (변경 금지)
```

> `02.Effects` · `03.Shaders` · `06.RenderPipeline` 은 폴더만 잡아둔 **placeholder**다.
> 이펙트/셰이더/렌더피처는 아래 로드맵 단계에서 채운다 — 지금 없는 것을 있는 것처럼 적지 않는다.

## 렌더 파이프라인
- **URP** 사용
- `99.Settings/` 내 URP 에셋은 직접 수정하지 않음 — 필요하면 새 Profile/RendererData 생성

## 로드맵 (미구현 — 방향만 정해둔 것)

> 아래는 **아직 코드가 없는** 계획이다. 진행 순서·체크리스트는 [TODO.md](TODO.md)에 있다.

1. **특수 기술(Special)** — 신규 모션 제작 후 기존 콤보/입력 시스템에 배선
2. **노티파이 트랙 확장 (이펙트)** — 본 소켓 바인딩, 구간형 노티파이, 이펙트 풀링.
   별도 이펙트 툴은 만들지 않고 **`AnimationConfig`의 Notify 시스템을 확장**해 처리.
3. **툰 셰이더 + RenderFeature** — 셀 셰이딩/림라이트 셰이더와 `ShaderGUI`(키워드 자동 관리),
   아웃라인/포스트 RenderFeature. 전투 중 셰이더 연출은 `MaterialPropertyBlock`으로 적용(머티리얼 오염 금지).
4. **모바일 빌드 & 최적화** — Android 실기 빌드 + Profiler 기반 최적화, Addressables 비동기 로딩.

## 작업 시 주의사항
- `99.Settings/` 내 URP 에셋 직접 수정 금지 — 새 Profile/RendererData 생성해서 사용
- Editor 전용 코드(`05.Editor/`)에 런타임 의존성 추가 금지
- VFX/Particle은 Prefab으로 만들어 `02.Effects/`에 저장
